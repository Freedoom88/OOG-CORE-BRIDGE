# OOG Core Bridge 1.1.2

- Исправлены стабильность запуска Core и передача управления от Launcher.
- Сохранены исправления WH PUT/GET, больших пакетов, TeleportToLocation, Appearing, ObjectDelete и REVERSE Restart.
- Добавлены пакетные команды работы с почтой, клановым хранилищем и Quest Inventory; поддерживаются большие количества, включая 20 млрд адены.
- STORE_SELL, STORE_BUY, TRADE_BUY и TRADE_SELL поддерживают до шести разных товаров за операцию. Сохранены команды закрытия продажи и скупки.
- SEND_PACKET поддерживает одиночную и повторную отправку: 1–1000 повторов, интервал по умолчанию 250 мс, настраиваемый 1–10000 мс; повторы отменяются при остановке/релоге/отключении.
- AUTO_TRADE поддерживает последовательные обмены и отмену без релога.
- TRADE_ME поддерживает выдачу до десяти видов предметов по игровому ЛС, последовательное добавление и подтверждение серверных ответов.
- BROKEN поддерживает массовую кристаллизацию экземпляров ItemID с настраиваемой задержкой.
- Сохранены FAST_DEATH, cooldown и другие рабочие функции предыдущей версии.

MAIN использует штатную лицензию, HWID и проверку обновлений. VPS EDITION поставляется отдельно.

MAIN Launcher и Core защищены вручную через VMProtect. Проверен запуск защищённой пары с действительным Launcher ticket. VPS EDITION распространяется отдельно и не входит в публичные файлы MAIN.
